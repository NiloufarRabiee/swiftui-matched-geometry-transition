# Security Policy

## Supported versions

The latest main branch receives maintenance and fixes.

## Reporting concerns

This is a local presentation component. It does not perform networking, collect information, or persist data. If you discover a security issue, contact the maintainer privately through the contact information on the GitHub profile. Please do not publish proof-of-concept exploits in a public issue before the maintainer has had a chance to investigate.

Use GitHub Issues for general bugs and feature requests.
