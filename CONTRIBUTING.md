# Contributing

Thank you for your interest in improving MatchedGeometryTransition.

1. Create a focused issue before proposing a significant API change.
2. Keep the package dependency-free and compatible with Swift 5.9, iOS 16+, and macOS 13+.
3. Do not introduce new public roles that collide with `"surface"`, the reserved gallery role.
4. Preserve VoiceOver access and Reduce Motion support.
5. Add tests for changes to `CardSelectionState` or `TransitionMetrics`.
6. Run `swift build` and `swift test` before opening a pull request.
7. Keep documentation, source comments, and examples in English.

Small pull requests with clear before/after behavior are preferred.

By contributing, you agree your work is distributed under the MIT License.
