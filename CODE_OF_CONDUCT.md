# Code of Conduct

We aim to make project participation welcoming, respectful, and constructive.

- Treat contributors with respect.
- Discuss technical decisions without personal attacks.
- Do not harass, threaten, or discriminate.
- Avoid sharing personal information without permission.
- Keep discussions relevant to the project.

Maintainers may edit, hide, or remove comments that violate these expectations. Report concerns privately through the maintainer's GitHub profile contact information.
