# Changelog

All notable changes to this project are documented here.

## 0.1.0 — 2026-11-04

### Added

- Generic SwiftUI card-to-detail gallery with matched surface geometry.
- Optional shared-element transitions for titles, artwork, and custom content.
- Adaptive grid, dimmed background, and detail dismissal callback.
- Reduce Motion support and accessible card selection.
- Identity-based selection reconciliation when data changes.
- Bounded layout configuration.
- Two usage examples and automated unit tests.
